# BunkrDownloader 对接文档

本文档说明如何把 BunkrDownloader 作为「插件」集成到你的另一个项目里，只需复制一个接口文件 `bunkr_api.py` 即可调用启动，无需改动 BunkrDownloader 内部代码。

## 一、原理

BunkrDownloader 的下载能力封装在 Python 后端 `gui_bridge.py` 中，它通过 **子进程 stdio** 对外暴露：

- 往 `stdin` 写一行 JSON（NDJSON）作为命令
- 从 `stdout` 读一行 JSON 作为事件

接口文件 `bunkr_api.py` 就是把这个「启动 + 写命令 + 读事件」的流程封装成了一个类 `BunkrAPI`。任何 Python 项目（包括 PyQt、FastAPI、脚本等）都能直接使用。

## 二、文件说明

| 文件 | 作用 |
|---|---|
| `bunkr_api.py` | **对接接口文件**（单文件，可复制到任意项目） |
| `gui_bridge.py` | BunkrDownloader 后端（无需改动） |
| `plugin/pyqt_integration.py` | PyQt5 + WebEngine 集成示例（可选参考） |

## 三、快速开始

### 1. 复制接口文件

把 `bunkr_api.py` 复制到你的项目里（放在哪里都行，不需要放在 BunkrDownloader 目录内）。

### 2. 调用启动

```python
from bunkr_api import BunkrAPI, is_bunkr_url, extract_bunkr_url

# project_root 指向 BunkrDownloader 项目根目录（含 gui_bridge.py）
api = BunkrAPI(project_root=r"D:\BunkrDownloader")

if not api.wait_ready():
    raise RuntimeError("BunkrDownloader 后端启动失败")

# 监听事件
api.on("log", lambda ev: print(f"[{ev.get('type')}] {ev.get('message')}"))

# 解析一个相册链接
api.inspect("https://bunkr.cr/a/xxxx")

# 用完后停止
# api.stop()
```

> `project_root` 不传时，默认取 `bunkr_api.py` 所在目录。复制到别的项目后请务必传入正确的项目根目录。

## 四、完整下载流程

```python
api = BunkrAPI(project_root=r"D:\BunkrDownloader")
api.wait_ready()

download_url = None
file_items = []  # 勾选要下载的文件

def on_inspect_complete(ev):
    global download_url, file_items
    download_url = ev.get("url") or ev.get("album_id")
    for it in ev.get("items", []):
        if it.get("status") == "ok":
            it["selected"] = True
            file_items.append(it)
    # 拿到文件列表后创建下载任务
    api.download(
        url=download_url,
        items=file_items,
        album_name=ev.get("album_name", ""),
    )

api.on("inspect_complete", on_inspect_complete)
api.on("file_progress", lambda ev: print(f"进度 {ev.get('filename')}: {ev.get('completed')}%"))
api.on("download_complete", lambda ev: print("全部完成"))

api.inspect("https://bunkr.cr/a/xxxx")
# 保持主程序运行，事件在后台线程触发
```

## 五、链接检测

```python
from bunkr_api import is_bunkr_url, extract_bunkr_url

text = "看这个 https://bunkr.cr/a/e8Bmwucj 相册"
if is_bunkr_url(text):
    url = extract_bunkr_url(text)  # -> "https://bunkr.cr/a/e8Bmwucj"
    api.inspect(url)
```

## 六、命令一览（`api` 方法）

| 方法 | 参数 | 说明 | 返回事件 |
|---|---|---|---|
| `inspect(url, options)` | 相册/文件链接 | 解析文件列表 | `inspect_complete` |
| `search(query, page, per_page, options)` | 关键词 | 搜索相册 | `search_result` |
| `download(url, items, options, album_name, album_id)` | 文件列表 | 创建下载任务 | `file_*` / `download_complete` |
| `get_tasks()` | - | 获取任务列表 | `tasks_snapshot` |
| `pause_task(task_id)` | 任务 ID | 暂停任务 | `tasks_snapshot` |
| `resume_task(task_id)` | 任务 ID | 继续任务 | `tasks_snapshot` |
| `cancel_task(task_id)` | 任务 ID | 取消任务 | `tasks_snapshot` |
| `remove_task(task_id)` | 任务 ID | 删除任务 | `tasks_snapshot` |
| `shutdown_after_done(enabled)` | 是否关机 | 完成后关机 | `log` |
| `get_history()` | - | 获取历史 | `history` |
| `delete_history(id, delete_file)` | 记录 ID | 删除历史 | `history` |
| `clear_cache()` | - | 清除缓存 | `cache_cleared` |

## 七、事件一览（`api.on(event, cb)`）

| 事件 | 说明 |
|---|---|
| `ready` | 后端就绪 |
| `log` | 日志（`type` / `message`） |
| `inspect_start` / `inspect_progress` / `inspect_complete` / `inspect_error` | 解析流程 |
| `search_start` / `search_result` / `search_error` | 搜索流程 |
| `download_start` / `file_start` / `file_progress` / `file_complete` / `download_complete` / `download_error` | 下载流程 |
| `tasks_snapshot` | 下载任务快照 |
| `history` | 历史记录 |
| `cache_cleared` | 缓存已清除 |

## 八、生命周期

```
BunkrAPI(project_root=...)   # 启动后端子进程
    ↓
wait_ready()                 # 等待 ready 事件
    ↓
on(...) / send(...)          # 订阅事件 / 发送命令
    ↓
stop()                       # 终止后端进程
```

## 九、依赖说明

- 接口文件 `bunkr_api.py` 只依赖 **Python 标准库**。
- 后端 `gui_bridge.py` 需要 BunkrDownloader 项目已安装依赖（`requests`、`aiohttp`、`beautifulsoup4` 等），且需要能访问外网。
- `python` 参数可指定解释器，例如 `BunkrAPI(project_root=..., python="python3")`。

## 十、注意事项

- 后端通过标准输出返回事件，`ensure_ascii` 已处理编码，前端收到的中文为正常 Unicode。
- 下载链接有有效期，后端在真正下载前会重新解析，请勿长期缓存下载链接。
- 大量并发下载可能触发反爬，建议通过 `options` 控制并发数，例如：

```python
options = {
    "connections": 4,        # 单文件分块连接数
    "concurrent_files": 2,   # 同时下载的文件数
    "rate_limit": 1024,      # 限速 KB/s，None 为不限速
}
api.download(url, items, options=options, album_name="xxx")
```
