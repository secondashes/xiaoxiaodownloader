# 三站接入 + 翻译重制 + 设置功能完善

## Context（为什么做这个）

用户请求扩展 BunkrDownloader GUI：
1. 接入三个三次元站点（xhamster / pornhub / xvideos），其中前两个用 X 站 OAuth 登录，第三个用邮箱密码 + 机器验证
2. 重制翻译功能——现有有道智云 API 因需配置 app_id/app_secret 用户反馈"根本不能正常使用"，改用 Google Translate unofficial endpoint（免费、无需 key、自动识别+中文输出）
3. 完善设置功能——新增不息屏、全局最小化快捷键、拟态（伪装成文档应用）三项
4. 通用基建：webview OAuth 通用框架（不只给新站用，未来其他站也可复用），机器验证弹窗让用户手动通过
5. 用户要求：每完成一个子项就存档（md + git commit + push），并在 md 里列出后续任务和剩余任务，防止任务链断裂

实施顺序（用户选定）：新站 → 翻译 → 设置

---

## 关键架构决策（已与用户确认）

| 子项 | 决策 | 理由 |
|------|------|------|
| X 站登录方式 | **webview 自动 OAuth** | 嵌入 webview 用 `persist:twitter` 共享 session，OAuth 跳转 x.com 自动带 cookie 完成授权；机器验证弹大 modal 让用户手动通过 |
| 翻译方案 | **Google Translate unofficial endpoint** | 免费、无需 key、自动识别+中文输出，国内走代理（复用 `twitter_proxy`） |
| 拟态意图 | **伪装成文档应用** | 窗口标题/任务栏图标/进程描述改成文档类型，隐藏悬浮框，只留托盘后台 |
| 实施顺序 | **新站→翻译→设置** | 先做最大工作量 |

## 阶段 1：三站接入

### 1.1 webview OAuth 通用框架（先做，给三站复用）

**新增文件**：
- `gui\src\components\WebviewLoginModal.vue` —— 通用 webview OAuth 弹窗组件

**修改文件**：
- `gui\electron\main.cjs`：新增 `SITE_SESSIONS` 注册表 + `setupSiteSession(site, proxy)` + IPC `site-inject-twitter-cookies`（用 `persist:twitter` 共享 session，**不跨域注入 cookie**，让 OAuth 跳转 x.com 时自动带）+ `site-get-cookies`（抓目标站 cookie）+ `site-set-proxy`
- `gui\electron\preload.cjs`：暴露 `siteInjectTwitterCookies(site)` / `siteGetCookies(site)` / `siteSetProxy(site, proxy)`
- `gui_bridge.py`：通用辅助 `_generic_set_cookies(site, cookie_str)` → 解析+存 theme_cache.dat+`check_login`；通用命令分发 `<site>_set_cookies` / `<site>_check_login` / `<site>_logout` / `<site>_set_proxy`

**WebviewLoginModal.vue 关键骨架**：
```vue
<n-modal v-model:show="visible" preset="card" :title="title" style="width:90%;max-width:1100px">
  <div class="wv-toolbar">后退/刷新/主页 + 状态提示 + "完成抓取"按钮</div>
  <webview ref="wvRef" :src="loginUrl" :partition="partition" class="login-webview"
    @did-navigate="onNav" @did-stop-loading="onStop" />
  <n-modal v-model:show="captchaVisible" :mask-closable="false" style="width:90%">
    <webview ref="captchaWvRef" :src="captchaUrl" :partition="partition" />
    <div>遇到人机验证，请在上方完成验证后点"已通过"</div>
  </n-modal>
</n-modal>
```
- props：`site`, `loginUrl`, `partition`（用 `persist:twitter` 共享 X 站 cookie）, `successPatterns:[RegExp]`, `captchaPatterns:[RegExp]`
- `onNav` 检测 captcha→弹大 modal；检测登录成功→`api.siteGetCookies(site)`→emit `login-success`

**关键技术点**：webview 用 `persist:twitter` session，OAuth 跳转 x.com 时自动带 X cookie 完成授权（**不跨域注入**）。回跳到站点域后抓取目标站 cookie 长期存 theme_cache.dat。

**验证**：手动点"用 Twitter 登录"→ webview 加载 → X cookie 自动授权回跳 → 抓 cookie → 重启恢复有效。

**存档点 AP1**：`feat: webview OAuth 通用框架（site session/inject/extract + WebviewLoginModal）`
