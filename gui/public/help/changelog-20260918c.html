修复更新 · 2026-09-18 / v1.2.48

返回逻辑 · Word 导出 · 品牌显示
三处硬伤一次补齐

「表世界」正式改名「美好世界」、程序显示名改为「小小浏览器」；下载管理可以原路返回刚才的网页；「保存为 Word」从大量站点失效修到实测可用。

🏷️一、品牌显示改名

「表世界」→ 美好世界，程序显示名 → 小小浏览器

此前界面上「表世界 / 里世界」的叫法容易让人困惑，程序名也沿用旧称呼。本版统一替换为更直观的说法，涉及所有用户可见位置：

  • 自定义标题栏徽标：里世界 / 美好世界 模式指示
  • 标题栏程序名、左侧登录面板标题：小小浏览器
  • 托盘图标提示、关闭确认弹窗、后台运行页（mimic）
  • 帮助文档、更新说明、三连 Alt 切换提示
标题栏 登录面板 托盘提示 关闭确认 后台运行页 帮助中心
注意：安装目录名、快捷方式名、开始菜单项仍保持「小小下载器」不变 —— 改名只影响界面显示，不会影响已安装的路径与升级。

↩️二、全链路返回逻辑

从网页进下载管理，现在能原路返回，且不丢浏览进度

之前从某个平台的网页点进「下载管理」，只能点首页按钮重置回平台选择墙，刚才在看的页面就丢了。本版新增了视图返回栈：

平台网页（B站某视频） → 下载管理 ↩ 返回 平台网页（回到刚才那条 URL）
  • 下载管理页顶部新增 ↩ 返回按钮，右上角 🏠 / ⊞ 也改为「返回」语义
  • 返回时恢复上次浏览的 URL（不再重置回站点首页）—— 每个平台单独记忆
  • 网页内导航（点链接换页）会实时记录当前地址，返回时精准还原
  • 切换平台 / 关闭平台时清空返回栈，避免跨站点串台
  • 栈为空时按钮回落为「返回平台选择」，不会出现按了没反应的死按钮

📄三、「保存为 Word」修复

从「很多站点失效 / 假成功」修到实测可用

旧版 Word 导出有四个致命问题，本版逐一解决：

问题
修复
单页应用（SPA）一滚动就触发跳转，执行上下文被销毁，导出直接中断
拆成「先滚动、后提取」两次注入；捕获上下文销毁错误自动重试 2 次
只用 <p> 取正文，div / span 结构的现代站点抓不到内容，导出空白
新增 TreeWalker 二轮兜底扫描，按可见性 + 文本长度智能补抓
导航栏、页脚、侧栏、评论区被一起导出，文档又臭又长
新增噪声区域识别（nav / footer / aside / header / comment），正文前先剔除
图片下载不走代理，外链图一张都下不到（实测 0/4）
图片下载器改为代理感知，自动尝试「直连 / 系统代理 / 配置代理 / PAC」四种组合（实测 4/4）
前端发完指令就显示成功，后端其实失败了也不提示（假成功）
前端改为监听 word_result 事件，成功/失败都有明确提示；超时 150 秒自动兜底报错
1038提取正文块
4 / 4图片下载成功
389 KB生成 .docx 大小

实测环境：Chromium 真实渲染抓取维基百科页面 → 后端生成 → 打开 .docx 校验（含 24 个表格结构）。

🎯怎么用这三个改动

看新名字

启动后标题栏右侧徽标显示「美好世界」，程序名显示「小小浏览器」；三连 Alt 仍可在美好世界 / 里世界间切换。

用返回

在任意平台网页里点进下载管理，看完后点顶部 ↩（或右上角 ⊞），即可带着原来的页码回到刚才那个网页。

导出 Word

在网页视图点「保存为 Word」，等待提示出现（成功会告诉你保存路径 + 图片成功/失败数量）；失败会明确报错，不再假成功。
